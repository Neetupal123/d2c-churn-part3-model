# Model Card

## Model Name
Customer Churn Prediction Model

## Intended Use
Predict customers likely to churn in next 60 days.

## Data Used
- Customer profile
- RFM features
- Web activity
- Support ticket history
- Campaign engagement

## Leakage Prevention
Only snapshot-date features were used.
Future information was excluded.

## Models Used
1. Logistic Regression
2. Random Forest Classifier

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1 Score
- ROC AUC

## Threshold Selection
Threshold = 0.5 selected for balanced precision and recall.

## Important Features
- Recency
- Frequency
- Monetary value
- Ticket count
- Campaign clicks

## Limitations
- Customer behavior may change over time.
- Model may not generalize to new acquisition channels.

## Ethical Risks
- Incorrect churn prediction may unfairly target customers.
- Human review should be included before major retention actions.

## Monitoring Needs
- Data drift
- Prediction drift
- Recall drop
- API failures

## When Not To Use
- Real-time fraud detection
- Credit approval decisions
