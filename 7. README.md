# D2C Customer Churn Prediction

## Objective
Predict customer churn risk for next 60 days.

## Files Included
- churn_model.ipynb
- model.pkl
- metrics.json
- error_analysis.md
- model_card.md
- requirements.txt

## Models Used
- Logistic Regression
- Random Forest

## Metrics
Model evaluated using:
- Accuracy
- Precision
- Recall
- F1 Score
- ROC AUC

## How To Run

```bash
pip install -r requirements.txt
```

Run notebook:
```bash
churn_model.ipynb
```
